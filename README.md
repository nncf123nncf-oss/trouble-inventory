# 困りごとの棚卸し

100日100プロダクトチャレンジ Day091（2026-11-06）

お仕事の種類を選び、いつもの作業の「週の回数」と「1回の時間」を選ぶと、次の3つが出るWebページです。

- 時間をとられている作業トップ3（週あたりの目安）
- その作業に近いかもしれない道具（100日チャレンジで作ったもの）
- そのまま送れる相談の文

## 使い方

`index.html` をブラウザで開きます。「見本を入れる（美容室）」「見本を入れる（教室）」で架空の例を入れられます。

## 扱うデータ

- 入力はこの端末のブラウザの中だけで扱い、当サイトには送信しません
- 入力は、この端末のブラウザ（localStorage）に下書きとして残ります
- 相談のフォームは、ボタンを押してご自身で開いたときだけ使われます。相談の文はフォームに自動では入りません（コピーして貼り付けます）
- 時間は選んだ回数と時間からの目安で、実際の作業時間を測るものではありません
- アクセス解析（Cloudflare Web Analytics）でページの閲覧状況を計測しています
